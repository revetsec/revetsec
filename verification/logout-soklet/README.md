This disposable loopback harness joins the exact core JAR, Java 17 common recipe JAR, separate test-only fixture JAR, Java 21 Soklet carrier JAR and selected framework JAR. It checks every supplied digest before starting Java, rejects local core/common class shadowing and unselected manifest dependencies, records actual runtime origins and source/class hashes, and requires process and listener cleanup. Runtime excludes JUnit and annotation JARs. Keep the five selected artifacts and built socket-fixture test classes; the harness does not download or build dependencies.

Run pure input controls with `python3 -m unittest discover -s verification/logout-soklet -p test_input_selection.py`. Run `python3 verification/logout-soklet/run.py --help` for required paths and five digest arguments. Output must be a new absolute directory. Select an existing built examples root with `--examples-root` and a JDK21 or27 with `--java-home`; the core and common recipe remain Java17. Supply `--delivery form` (default) or `get` as a trusted startup choice. Normal runs exercise actual raw HTTP, genuine synthetic OIDC authentication, local-first ordering, exact field multiplicity, one-save delivery, all uncertainty classes, checked interruption, shared eight/ninth admission and atomic return races. `--padding 6000` isolates large-hint FORM success versus GET refusal. `--fault-only --metadata-fault outage|unsupported` uses a fresh process and asserts discovery count1→2 for cause-specific evidence. The synthetic provider, login, environment-credential and fault-control routes are test-only. They create application sessions only after genuine code/PKCE/token-signature authentication and never belong in deployment. Receipts hash query/body data; do not add cleartext token, state, cookie or response logging.
