# Contract-test fixtures

Deliberate violations of Revetsec's contract tests. `ContractMetaTests` points each checker at one of these
trees and asserts that every seeded violation is detected, and that the compliant controls are not flagged.

| Directory | Checker | Seeded violations |
|---|---|---|
| `public-api/` | `PublicApiContractTests` | a public record, missing and duplicate thread-safety markers, missing Javadoc and `@since`, missing nullness, `of*`/`create*`/`new*` factory names, a non-final concrete class, a sealed concrete class reopened by a non-sealed subclass (and a sealed one with a final subclass as a control), implicit and explicit public or protected constructors (including on a class listed in `R1_EXCEPTIONS`), members inherited from a package-private base class, and verified (R17) types: one with a public constructor and a builder, one neither final nor sealed, a public subtype, one sealed with a public permitted subclass, and factories, a top-level builder and a field that return or hold one (directly, as a type argument, through a type-variable bound, or as a subtype), plus a listed verified-type source whose static factory and static field are still reported. From M1: unsealed exported abstract classes (top-level, nested, and a `non-sealed` subclass of a sealed exception); exported Throwables that do not extend the tree's own `RevetsecException`, declare no `serialVersionUID`, declare it as an `int`, or declare a `long` one that is not `final`, not `static` or not `private`, or have a public or protected static method (declared, or inherited from a package-private base), with a subclass of an exported exception as a control (a static method it inherits from there is reported only once, on the parent); and observer interfaces with a field, a `disabledInstance()` of the wrong type, one that takes an argument, another static method, an abstract hook (declared, or inherited from a package-private interface, from a package-private interface named like an observer, or from an exported interface that is not an observer), a hook that returns a value, hook parameters outside the allowlist (a primitive, an array, a collection, `Optional`, `Object`, a JDK exception, `BigDecimal`, `Character`, a Revetsec non-exception type, an exception outside `RevetsecException` and a type variable), or no `disabledInstance()`, with an observer that follows every rule, one that extends it, and one that extends the observer that breaks them (whose inherited members are reported only once, on the parent) as controls. | `claims/` | `ClaimsLintTests` | banned claim terms in Markdown, Javadoc (`/** */` and `///`), `package.html`, `doc-files/`, the Javadoc overview and the POM description, including terms wrapped across lines, joined by no-break spaces or dashes, or spelled with HTML entities; plus stale, malformed and too-broad allowlist entries |

The real contract tests never scan this directory: the Java files here are not on any source path, and
`ClaimsLintTests` excludes `src/test/resources/contract-fixtures/` when it lints the repository.
