Revetsec is a zero-dependency Java library for OAuth 2.0 clients and resource servers, OpenID Connect relying parties, JOSE, SAML 2.0 service providers and SCIM 2.0 servers.

Revetsec is pre-release software (1.0.0-SNAPSHOT). Its API may change in any way before 1.0.0.

Packages under com.revetsec.internal are not API and are not documented here.
